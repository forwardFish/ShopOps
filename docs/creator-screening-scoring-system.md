# 达人筛选评分系统说明

本文档说明当前“洗面奶”达人采集与筛选流程中的评分系统。评分系统用于把搜索得到的达人候选数据、视频信息、真实评论样本和基础账号信息统一转成可复核的 A/B/C 候选结论，并写入飞书多维表格 `达人筛选表`。

## 1. 评分系统目标

当前评分系统服务于达人初筛，不直接替代人工决策。

核心目标是：

1. 从关键词搜索结果中批量发现候选达人。
2. 保存每个候选达人的来源、搜索关键词、视频信息、评论原始数据和采集时间。
3. 用统一规则计算达人与产品的相关性、商业潜力、评论有效性和风险。
4. 输出 `综合评分`、`评分结论`、`AI初筛等级` 和 `评分依据`，供人工确认 A 类达人。

当前流程更偏向 MVP 阶段的“可验证采样”，重点是拿到真实有效评论作为评分依据，而不是一次性追求完整达人画像。

## 4. 评论原始数据口径

当前系统会把真实评论样本写入 `评论原始数据JSON` 字段。

为了降低隐私风险和无关数据污染，评论原始数据只保留和判断相关的最小字段：

```text
cid
text
create_time
create_time_text
digg_count
reply_comment_total
commenter_nickname
```

当前不会保存评论用户 UID、头像、主页链接等不必要身份信息。

## 5. 评论证据等级

评论证据等级用于说明评分依据的可靠程度。

### L1-弱证据

没有拿到直接评论，只能基于搜索卡片、视频标题、简介或主页可见文本做初步判断。

适用情况：

```text
评论接口失败
评论为空
只拿到达人或视频表层信息
```

评分使用上，L1 只能作为弱参考。

### L2-可见文本信号

页面或已有文本中出现购买意图、使用问题、质疑等明确表达，但不一定来自结构化评论接口。

适用情况：

```text
可见文本中出现“求链接”“好用吗”“广告”等信号
但没有完整评论接口样本
```

### L3-真实评论接口抽样

已通过真实评论接口拿到评论样本，并写入 `评论原始数据JSON`。

适用情况：

```text
评论接口状态为 success
真实评论条数 > 0
评论原始数据JSON 非空
```

当前 50 条达人数据的评论证据等级应以 L3 为主，因为每条记录都要求抓取到真实评论后才写入。

## 6. 评论信号识别规则

系统会从评论文本中识别四类信号。

### 6.1 购买意图信号

代表评论用户可能有购买兴趣。

关键词包括：

```text
怎么买
求链接
链接
同款
在哪里买
多少钱
已下单
想买
种草
```

命中后会增加 `购买意图评论数`，并影响 `评论有效性评分`。

### 6.2 使用问题信号

代表评论用户在询问适用人群、肤质、效果或使用风险。

关键词包括：

```text
好用吗
适合
敏感肌
油皮
干皮
痘痘
黑头
毛孔
刺痛
会不会
```

这类评论对洗面奶产品尤其重要，因为它能说明用户不是泛泛互动，而是在围绕真实使用场景提问。

### 6.3 质疑与风险信号

代表评论中存在负面反馈、质疑或信任风险。

关键词包括：

```text
广告
智商税
踩雷
没用
假
贵
翻车
不值
骗人
```

这类信号会影响 `评论风险结论` 和 `风险评分`。

### 6.4 产品相关信号

代表内容与洗面奶或护肤场景相关。

关键词包括：

```text
洗面奶
洁面
洗脸
护肤
控油
毛孔
黑头
痘
敏感肌
油皮
```

这类信号既影响评论判断，也会影响内容相关判断。

## 7. 四项子评分

综合评分由四个子评分组成：

```text
内容相关评分
商业匹配评分
评论有效性评分
风险评分
```

每项评分满分 100 分。

### 7.1 内容相关评分

内容相关评分判断达人内容是否和洗面奶、洁面、护肤、美妆等产品场景相关。

当前相关词包括：

```text
洗面奶
洁面
洗脸
护肤
美妆
控油
油皮
毛孔
黑头
祛痘
旗舰店
```

计算规则：

```text
内容相关评分 = 35 + 去重相关词命中数 × 9
最高不超过 100
```

示例：

```text
命中：洗面奶、洁面、油皮、控油
去重命中数：4
内容相关评分 = 35 + 4 × 9 = 71
```

解释：

```text
35 分是基础分，代表候选来自目标关键词搜索结果。
每多命中一个不同相关词，说明内容和产品场景更贴近。
```

### 7.2 商业匹配评分

商业匹配评分判断达人账号是否具备基本商业转化潜力。

当前主要参考：

```text
粉丝数
获赞数
```

计算规则：

```text
商业匹配评分 = 35 + min(粉丝数 / 20000, 25) + min(获赞数 / 200000, 25)
最高不超过 100
```

解释：

```text
35 分是基础商业可观察分。
粉丝数最多贡献 25 分。
获赞数最多贡献 25 分。
```

示例：

```text
粉丝数：200000
获赞数：1000000

粉丝贡献 = min(200000 / 20000, 25) = 10
获赞贡献 = min(1000000 / 200000, 25) = 5

商业匹配评分 = 35 + 10 + 5 = 50
```

当前快速评论模式下，部分搜索卡片不会提供粉丝数、抖音号、主页链接等字段。遇到缺失时，系统会按 0 处理，因此商业匹配评分会偏保守。

### 7.3 评论有效性评分

评论有效性评分判断评论区是否存在真实、有效、和购买或使用决策有关的讨论。

有效评论信号包括：

```text
购买意图
使用问题
质疑风险
产品相关讨论
```

计算规则分两种情况。

如果评论证据等级为 L2 或 L3：

```text
评论有效性评分 = 35 + min(有效评论数 × 8, 30)
最高不超过 100
```

如果评论证据等级为 L1：

```text
评论有效性评分 = 20 + min(有效评论数 × 5, 15)
最高不超过 100
```

解释：

```text
L3 代表拿到真实评论接口样本，所以同样的有效评论信号权重更高。
L1 只有弱证据，因此基础分和上限贡献都更低。
```

当前 `有效评论数` 是基于关键词信号命中计算的有效信号数，不等同于完整 NLP 语义分类后的有效评论条数。后续可以升级为逐条评论语义分类。

### 7.4 风险评分

风险评分用于惩罚明显负面或可信度不足的候选达人。

初始规则：

```text
默认风险评分 = 85
```

评论风险影响：

```text
评论风险结论 = 低 → 风险评分 85
评论风险结论 = 中 → 风险评分 70
评论风险结论 = 高 → 风险评分 45
```

账号数据缺失影响：

```text
如果粉丝数为 0 或缺失，风险评分再减 15
```

解释：

```text
负面评论越多，达人合作风险越高。
基础账号信息缺失时，说明当前数据不足，需要人工复核，所以风险评分降低。
```

## 8. 综合评分公式

综合评分使用加权平均：

```text
综合评分 =
  内容相关评分 × 0.35
+ 商业匹配评分 × 0.25
+ 评论有效性评分 × 0.20
+ 风险评分 × 0.20
```

权重解释：

```text
内容相关评分 35%：优先保证达人和洗面奶产品场景匹配。
商业匹配评分 25%：考虑达人账号规模和商业潜力。
评论有效性评分 20%：判断评论区是否有真实需求和反馈。
风险评分 20%：控制负面评论、数据缺失和合作风险。
```

当前公式版本：

```text
creator-screening-v2-comment-evidence-weighted
```

## 9. 评分结论规则

系统会输出 `评分结论`，用于人工筛选优先级。

### A 类候选

规则：

```text
综合评分 >= 70
且 内容相关评分 >= 65
```

结论：

```text
A类候选-建议人工确认
```

含义：

```text
内容和产品高度相关，综合表现较好，建议进入人工确认。
```

### B 类候选

规则：

```text
综合评分 >= 55
但不满足 A 类条件
```

结论：

```text
B类候选-可复核
```

含义：

```text
有一定价值，但可能存在信息缺失、评论信号不足或商业数据较弱，需要人工二次判断。
```

### C 类候选

规则：

```text
综合评分 < 55
```

结论：

```text
C类候选-暂缓
```

含义：

```text
当前证据不足或匹配度较低，暂不建议优先进入授权和报价流程。
```

## 10. AI 初筛等级和评分结论的区别

系统中有两个判断结果：

```text
AI初筛等级
评分结论
```

两者不是同一个字段。

### AI 初筛等级

`AI初筛等级` 更像快速文本判断，主要看达人名称、简介、视频标题、评论等文本是否出现强相关词。

当前规则：

```text
如果文本包含“洗面奶”或“洁面”，并且相关词命中数 >= 2 → A
如果命中任意相关词 → B
否则 → C
```

强相关词包括：

```text
洗面奶
洁面
护肤
美妆
祛痘
控油
毛孔
黑头
旗舰店
```

### 评分结论

`评分结论` 是基于四项子评分加权后的结果，更适合排序和批量筛选。

建议使用方式：

```text
先按评分结论筛选 A 类和 B 类
再看 AI初筛原因、评论原始数据JSON 和评分依据
最后由人工确认是否进入授权/报价流程
```

## 11. 评论评分依据字段

`评论评分依据` 字段用于给人工解释为什么评论有效或有风险。

它通常包含：

```text
评论证据等级
评论样本数量
购买意图命中
使用问题命中
质疑风险命中
高频问题摘要
采样限制
```

其中 `评论采样限制` 会说明当前评论不是全量评论，而是抽样样本。当前系统适合做第一阶段筛选，不适合直接作为最终商务报价依据。

## 12. 示例计算

假设某达人数据如下：

```text
搜索关键词：洗面奶
文本命中相关词：洗面奶、洁面、控油、油皮
粉丝数：100000
获赞数：800000
评论证据等级：L3-真实评论接口抽样
有效评论数：4
评论风险结论：低
```

计算：

```text
内容相关评分 = 35 + 4 × 9 = 71

商业匹配评分 =
35 + min(100000 / 20000, 25) + min(800000 / 200000, 25)
= 35 + 5 + 4
= 44

评论有效性评分 =
35 + min(4 × 8, 30)
= 35 + 30
= 65

风险评分 = 85

综合评分 =
71 × 0.35 + 44 × 0.25 + 65 × 0.20 + 85 × 0.20
= 24.85 + 11 + 13 + 17
= 65.85
```

结论：

```text
B类候选-可复核
```

虽然内容相关性较好，评论也有真实证据，但商业匹配评分偏低，所以先进入 B 类复核。

## 13. 当前系统的优势

当前评分系统的优势是：

```text
1. 每条记录都保留搜索关键词，方便追溯来源。
2. 评论原始数据进入飞书，人工可以直接复核。
3. 评分依据可解释，不是黑盒分数。
4. 评论证据等级区分了弱证据和真实评论接口抽样。
5. A/B/C 结论可以直接衔接人工确认和授权报价流程。
```

## 14. 当前系统的限制

当前系统仍然是 MVP 版本，有以下限制：

```text
1. 快速评论模式优先获取真实评论，部分达人主页信息可能不完整。
2. 粉丝数、抖音号、主页链接等字段依赖搜索卡片或主页抓取，搜索卡片不提供时会为空。
3. 评论样本是抽样，不是全量评论。
4. 当前有效评论数基于关键词命中，不是完整语义模型判断。
5. 重复话术比例和无效评论比例还可以进一步升级为逐条评论统计。
6. 评论截图 OCR 和评论接口数据还没有完全合并为统一证据链。
7. 当前评分适合初筛，不建议直接作为最终达人报价依据。
```

## 15. 后续升级建议

建议下一阶段升级方向：

```text
1. 增加主页深度采集，补齐粉丝数、获赞数、抖音号、简介和主页截图。
2. 评论从关键词命中升级为 AI 逐条语义分类。
3. 增加评论情绪评分、真实用户问题聚类和购买意图强度。
4. 增加重复评论识别，过滤水军、刷屏和模板话术。
5. 增加达人历史带货内容识别，判断是否适合洗面奶品类。
6. 把 A 类候选自动进入“人工确认”视图。
7. 人工确认后，新增授权状态、报价状态、寄样状态和合作结果字段。
```

## 17. 推荐人工使用方式

人工确认时建议按以下顺序看：

```text
1. 先筛选 评分结论 = A类候选-建议人工确认。
2. 查看 搜索关键词，确认是否来自目标产品场景。
3. 查看 达人名称、简介、粉丝数、获赞数。
4. 查看 最近视频标题和评论来源作品标题。
5. 打开 评论原始数据JSON，确认评论是否真实、自然、和产品有关。
6. 查看 评论风险结论 和 质疑样例3条。
7. 最后决定 人工确认状态。
```

只有人工确认后的 A 类达人，才建议进入授权、报价、寄样和合作流程。

## 18. 反注水与有效达人识别补充

当前评分系统可以判断达人是否和洗面奶产品相关，也可以判断评论区是否存在真实用户问题。但它还不能充分判断“粉丝是否注水”。

原因是：当前快速评论采集模式优先保证真实评论数据，很多记录没有稳定拿到粉丝数、主页总获赞、公开视频列表、播放量、连续视频点赞、评论率和发布时间。因此当前系统更适合做“第一阶段相关性筛选”，还不适合直接判断达人账号质量。

### 18.1 为什么粉丝数不能单独作为判断依据

粉丝多不等于有效达人。

典型风险包括：

```text
1. 粉丝很多，但最近视频点赞很少。
2. 粉丝很多，但评论很少。
3. 点赞很多，但评论区全是表情、666、无意义夸赞。
4. 单条视频爆过，但最近 10 条视频普遍低互动。
5. 粉丝数和获赞数很高，但内容和产品类目不匹配。
6. 评论看起来很多，但大量重复话术、模板话术或品牌硬广。
7. 账号近期断更，历史数据好但当前没有转化价值。
```

所以反注水不能只看粉丝数，必须看“粉丝、播放、点赞、评论、收藏、转发、评论质量、近期稳定性”的组合。

### 18.2 建议新增字段

建议在飞书 `达人筛选表` 中新增以下字段：

```text
主页粉丝数
主页总获赞数
主页作品数
近10条视频平均点赞
近10条视频点赞中位数
近10条视频平均评论
近10条视频评论中位数
近10条视频平均收藏
近10条视频发布时间跨度
最高点赞视频点赞数
最低点赞视频点赞数
爆款依赖度
粉丝点赞比
粉丝评论比
评论点赞比
有效评论率
无意义评论率
重复评论率
疑似水评率
近期活跃评分
互动真实性评分
注水风险评分
注水风险结论
有效达人结论
反注水评分依据
```
这些字段可以把“看起来粉丝多”拆成“真实互动是否稳定”。

### 18.3 核心反注水指标

#### 18.3.1 粉丝点赞比

计算：

```text
粉丝点赞比 = 近10条视频平均点赞 / 主页粉丝数
```

用途：

```text
判断粉丝是否真的会看、会点赞。
```

参考判断：

```text
粉丝点赞比很低：粉丝可能沉默、低活跃或存在注水风险。
粉丝点赞比稳定：账号粉丝质量相对更可信。
```

#### 18.3.2 粉丝评论比

计算：

```text
粉丝评论比 = 近10条视频平均评论 / 主页粉丝数
```

用途：

```text
判断粉丝是否愿意互动和提问。
```

对洗面奶这类产品，评论区提问非常重要。有效评论比纯点赞更接近转化信号。

#### 18.3.3 评论点赞比

计算：

```text
评论点赞比 = 近10条视频平均评论 / 近10条视频平均点赞
```

用途：

```text
判断互动结构是否自然。
```

异常情况：

```text
点赞很高但评论极少：可能是浅层曝光、买赞或内容不激发购买讨论。
评论很多但内容高度重复：可能是水评、控评或活动刷评。
```

#### 18.3.4 爆款依赖度

计算：

```text
爆款依赖度 = 最高点赞视频点赞数 / 近10条视频点赞中位数
```

用途：

```text
判断达人是否靠单条爆款撑起数据。
```

风险：

```text
爆款依赖度过高，说明账号表现不稳定。
```

更稳的达人通常不是只有一条视频高，而是多条视频都能保持基本互动。

#### 18.3.5 有效评论率

计算：

```text
有效评论率 = 有效评论数 / 评论样本数
```

有效评论包括：

```text
购买意图
肤质问题
产品适配问题
使用反馈
真实质疑
品牌对比
复购反馈
```

无意义评论包括：

```text
666
哈哈
表情刷屏
单字夸赞
无上下文@好友
明显模板话术
与产品无关内容
```

#### 18.3.6 重复评论率

计算：

```text
重复评论率 = 高相似评论数 / 评论样本数
```

用途：

```text
判断评论区是否存在刷评、模板评论或营销水评。
```

判断方法：

```text
1. 完全相同文本重复。
2. 高度相似文本重复。
3. 多条评论集中夸同一个品牌但表达方式接近。
4. 评论时间高度集中。
5. 评论昵称风格异常相似。
```

### 18.4 建议新增“互动真实性评分”

互动真实性评分满分 100 分。

建议公式：

```text
互动真实性评分 =
  粉丝点赞健康度 × 0.25
+ 粉丝评论健康度 × 0.20
+ 评论点赞结构健康度 × 0.15
+ 近10条视频稳定性 × 0.20
+ 有效评论率 × 0.15
+ 低重复评论奖励 × 0.05
```

解释：

```text
粉丝点赞健康度：粉丝是否真的产生点赞。
粉丝评论健康度：粉丝是否真的产生讨论。
评论点赞结构健康度：点赞和评论是否匹配。
近10条视频稳定性：是否多条视频都有稳定互动。
有效评论率：评论是否围绕真实购买和使用问题。
低重复评论奖励：评论是否自然，而不是模板化。
```

### 18.5 建议新增“注水风险评分”

注水风险评分满分 100 分，分数越高风险越大。

建议规则：

```text
粉丝很多但近10条平均点赞极低：+25
粉丝很多但近10条平均评论极低：+20
爆款依赖度过高：+15
无意义评论率高：+15
重复评论率高：+15
近期断更或发布不稳定：+10
主页总获赞和作品表现不匹配：+10
```

风险结论：

```text
0-29：低注水风险
30-59：中注水风险
60-100：高注水风险
```

### 18.6 建议把反注水作为 A 类硬门槛

原本 A 类规则是：

```text
综合评分 >= 70
且 内容相关评分 >= 65
```

建议升级为：

```text
综合评分 >= 70
且 内容相关评分 >= 65
且 互动真实性评分 >= 60
且 注水风险评分 < 60
且 有效评论率 >= 30%
```

这样可以避免出现：

```text
内容相关，但账号互动虚。
粉丝很多，但近期视频没人看。
单条视频很火，但达人整体不稳定。
评论很多，但有效购买问题很少。
```

### 18.7 有效达人结论

建议新增一个字段 `有效达人结论`。

规则：

```text
A类有效达人：
内容相关，评论有效，互动真实，注水风险低，可进入人工确认。

B类观察达人：
内容相关，但账号数据或互动真实性不足，需要补采主页和近10条视频。

C类暂缓达人：
内容弱相关、评论弱、互动低或注水风险高，暂不进入授权报价。

D类排除达人：
明显无关、明显水评、明显搬运、明显低质营销号。
```

### 18.8 当前这批 50 条数据的判断边界

当前这批数据已经可以判断：

```text
1. 是否由洗面奶相关关键词搜索得到。
2. 视频标题和评论是否围绕洗面奶、洁面、控油、油皮等场景。
3. 是否抓到真实公开评论。
4. 评论里是否出现真实使用问题、购买意图或质疑。
5. 哪些达人值得进入下一轮主页补采。
```

当前这批数据还不能充分判断：

```text
1. 粉丝是否注水。
2. 达人账号整体互动是否稳定。
3. 近10条视频是否普遍低赞低评。
4. 是否只有单条爆款。
5. 评论区是否存在大规模重复话术。
6. 账号是否长期断更或近期商业内容过多。
```

因此，当前阶段不要直接说“这个达人没有注水”。更准确的说法是：

```text
该达人在当前样本中内容相关、评论真实且有有效讨论，建议进入下一轮反注水复核。
```

### 18.9 下一步采集建议

为了找到真正有效、没有明显注水的达人，下一轮应该从当前候选中挑出 B 类以上达人，补采以下数据：

```text
1. 达人主页粉丝数、总获赞数、作品数。
2. 近10条视频的点赞、评论、收藏、转发、发布时间。
3. 每条视频首批评论样本。
4. 评论文本相似度和无意义评论比例。
5. 近10条视频是否都和护肤/洁面/美妆相关。
6. 是否存在高频品牌硬广、重复植入或低质混剪。
```

补采后再输出最终字段：

```text
互动真实性评分
注水风险评分
注水风险结论
有效达人结论
反注水评分依据
```

## 19. 机器优先筛人版本

为了减少人工筛选时间，评分系统需要从“辅助人工判断”升级为“机器先淘汰大部分候选，人工只看少量高价值对象”。

这一版的核心原则是：

```text
机器先过滤 70%-90% 低价值候选。
人工只复核 S/A 级达人。
B 级只补采，不付款。
C 级暂不投入。
D 级移出达人池。
```

### 19.1 新增 ROI 筛选等级

新增字段：

```text
ROI筛选等级
ROI筛选分
评论质量评分
互动信号评分
注水风险评分
账号类型判断
主要拦截原因
建议动作
```

等级定义：

```text
S-优先联系小额测试
A-进入报价沟通
B-补采主页后再决定
C-暂不投入
D-非达人池
```

### 19.2 S 级达人门槛

S 级不是“看起来不错”，而是机器认为可以优先进入小额测试的达人。

当前规则：

```text
账号类型判断 = 达人疑似
无主要拦截原因
ROI筛选分 >= 75
内容相关评分 >= 60
评论质量评分 >= 80
评论接口返回总数 >= 100
视频最高可见热度 >= 1000
注水风险评分 < 35
```

建议动作：

```text
优先联系。
谈寄样 + 低基础费 + 佣金。
单个达人首测预算控制在 500-700 元以内。
```

### 19.3 A 级达人门槛

A 级是值得沟通报价，但还不应该直接付款的达人。

当前规则：

```text
账号类型判断 = 达人疑似
主要拦截原因 <= 1 个
ROI筛选分 >= 68
评论质量评分 >= 75
评论接口返回总数 >= 50
视频最高可见热度 >= 300
注水风险评分 < 45
```

建议动作：

```text
可以联系报价。
必须先要主页数据和近10条视频截图。
报价合理后再进入小额测试。
```

### 19.4 B 级达人门槛

B 级说明内容和评论可能有价值，但当前证据还不够投钱。

当前规则：

```text
内容相关评分 >= 60
评论质量评分 >= 60
但未达到 S/A 门槛
```

建议动作：

```text
只补采主页粉丝、近10条视频点赞评论、报价。
暂不付款。
```

### 19.5 C 级达人

C 级说明当前数据不支持投入。

常见原因：

```text
内容相关度不足
真实评论样本过少
有意义评论比例偏低
评论总量过低
注水/低质互动风险偏高
```

建议动作：

```text
暂不投入。
除非后续补采数据显著改善，否则不进入人工沟通。
```

### 19.6 D 级非达人池

D 级用于把品牌号、官方号、直播间号和专场号从达人池中移出去。

识别信号包括：

```text
官方
旗舰店
直播间
专场
品牌
```

建议动作：

```text
移出达人池。
如果后续有品牌自播或渠道合作需求，再单独评估。
```

### 19.7 ROI 筛选分公式

ROI 筛选分用于机器排序。

当前公式：

```text
ROI筛选分 =
  内容相关评分 × 0.25
+ 评论质量评分 × 0.30
+ 互动信号评分 × 0.20
+ (100 - 注水风险评分) × 0.15
+ 原综合评分 × 0.10
```

权重解释：

```text
评论质量评分 30%：优先看评论区是否有真实购买、使用、肤质和产品问题。
内容相关评分 25%：达人内容必须和洗面奶/洁面/护肤场景相关。
互动信号评分 20%：用可见热度和评论总量判断是否有基本传播能力。
低注水风险 15%：过滤低质互动、无意义评论、重复评论和疑似非达人账号。
原综合评分 10%：兼容上一版评分系统。
```

### 19.8 评论质量评分

评论质量评分满分 100。

加分项：

```text
有意义评论率高
产品相关评论多
出现购买意图
出现真实使用问题
出现肤质、控油、毛孔、敏感肌等决策问题
```

扣分项：

```text
评论样本少于 5 条
无意义评论比例高
重复评论比例高
质疑评论过多
评论和产品无关
```

### 19.9 互动信号评分

互动信号评分不是完整互动真实性评分，因为当前还缺主页和近10条视频。它是第一轮搜索数据里的弱互动判断。

参考字段：

```text
视频1/2/3可见热度
评论接口返回总数
有意义评论率
```

如果后续补采主页，应替换为：

```text
近10条视频平均点赞
近10条视频点赞中位数
近10条视频平均评论
近10条视频评论中位数
粉丝点赞比
粉丝评论比
评论点赞比
爆款依赖度
```

### 19.10 注水风险评分

注水风险评分越高，越不建议投入。

当前第一轮会惩罚：

```text
无意义评论比例高
重复评论比例高
评论总量过低
视频可见热度过低
评论风险为中/高
疑似品牌号/官方号/直播间
促销话术多但真实问题少
```

当前第一轮会降低风险：

```text
有意义评论率高
产品相关评论率高
评论总量 >= 100
视频最高可见热度 >= 1000
```
